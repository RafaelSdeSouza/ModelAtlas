Astronomy case studies
======================

These examples use measured photometry and spectroscopy from the Sloan Digital
Sky Survey. Each analysis fits a hexagonal self-organizing map using colors and
then summarizes spectroscopic quantities on plates held out from training. The
example pages explain the sample selection, units, data downloads, and what
can be inferred from the maps.

See :doc:`../guide/sdss_data` for the upstream catalogues and the commands to
rebuild the bundled subsets.
